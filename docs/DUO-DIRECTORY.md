# Duo Discover extension

Static, self-contained directory at /duo, added on 29 October 2026. Public files live solely in public/duo. One Next.js rewrite maps /duo to /duo/index.html. Existing page components, shared styles, navigation, backend, environment configuration and domains remain unchanged. Production paths are rooted at /duo to work without a trailing slash.

Source authored separately in the Duo Discover Sites project. That Site keeps owner-only access. Public publication uses the existing Flutterly Vercel project and certificate. No GoDaddy nameserver/DNS changes are required for this extension.

Seven actual UK Store listings/icons; all Free + IAP at the dated snapshot. Only Sipli has verified-dimension, developer-owned actual Duo simulator captures. Other six omit ordinary iPhone/iPad images and explicitly state Duo media unavailable. Gallery preserves aspect ratios and distinguishes inner landscape, inner portrait and cover portrait. No independent physical-device testing is claimed.

No forms, accounts, personal data collection, analytics, active sponsors/affiliate payments, checkout, or proposed-price purchase affordances are present. Revenue experiments remain future owner decisions.

Evidence and rights/provenance are documented in the canonical Duo Discover source: DUO-MEDIA.md, ASSET-USE.md, SOURCES.md, research/duo-media-provenance.json. Captures are delivered as lossless WebP, at original dimensions, with decoded pixel equality verified.
